# KramaTek V11 — Modern AI / IT Visual Upgrade

This version is based on the approved V10 Modern structure.

## What changed
- Replaced the previous data-company / dashboard-style visual library.
- Added 31 locally bundled modern AI/IT visuals.
- Visual direction now emphasizes:
  - human + AI collaboration
  - AI agents and intelligent applications
  - cloud and modern infrastructure
  - software/digital engineering
  - automation and robotics
  - enterprise technology teams
  - modern AI interfaces
- Each industry uses a separate hero and secondary visual.
- Each service has separate card and detail-page imagery.
- Homepage rotates four different AI/IT visual concepts.

## What was deliberately NOT changed
- Header navigation implementation.
- Hard `href` links in the desktop/mobile header.
- React Router route definitions.
- Vercel filesystem-first + SPA fallback configuration.
- The clean original KramaTek icon asset from V10; the screenshot supplied later was NOT used as the logo.
