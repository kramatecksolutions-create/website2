# KramaTek V10 Modern Final

Focused update of the approved V10 design.

What changed:
- Removed the 01/02/03/04/05 numbers from the premium header capsule.
- Kept the icon-led header presentation.
- Kept hard browser links in the main header so navigation behavior is not weakened.
- Kept Vercel filesystem-first routing + SPA fallback.
- Replaced diagram/data-company-looking imagery with modern IT/AI company visuals:
  AI interfaces, people + technology, intelligent applications, cloud, automation,
  digital engineering and enterprise collaboration.
- Service imagery is now visually distinct by service.
- Industry pages keep different hero and detail images rather than repeating one image twice.
- Platform, Why KramaTek, Insights and Contact also use modern IT/AI visual language.
