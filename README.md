# KramaTek Enterprise Ultimate V10

This version deliberately keeps the stronger V6/V7 visual language while fixing the recurring reliability and mobile issues.

- 25 unique local visual assets bundled by Vite; no external image hosts.
- 4 automatic homepage hero images + matching rotating copy.
- Unique card/hero imagery for each service.
- Unique imagery for each industry, Platform, Why KramaTek, Insights, and Contact.
- Original KramaTek horizontal logo shown large on a clean white header; no gold background.
- Fresh client wordmark visuals in a large floating marquee.
- Services and Industries overview routes plus all detail routes.
- React Router NavLink used consistently.
- Vercel SPA rewrite included for direct URLs.
- Dedicated mobile sizing prevents clipped cards / giant blank image areas.

Vercel:
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
Root Directory: ./
