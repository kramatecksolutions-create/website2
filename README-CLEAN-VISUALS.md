# KramaTek Clean Visuals Release

This repository is based on the existing working KramaTek Vite/Vercel codebase. Changes are limited to the website visual asset system and visual QA documentation. Routes, navigation, contact details, page copy, and Vercel routing are preserved.

## Image rules applied
- 34 physical local JPEGs in `src/assets/visuals/`
- 3840 × 2160 final dimensions
- unique source composition for every placement
- no reused source between hero/detail placements
- exact master KramaTek logo composited on reception/contact scenes
- reduced robots / oversized sci-fi visuals compared with the rejected batch
- mild contrast and edge enhancement for cleaner browser rendering

Important: 3840 × 2160 is the final output dimension. Some source compositions were created below native 4K, so this release does not claim native-camera 4K detail for every source.
